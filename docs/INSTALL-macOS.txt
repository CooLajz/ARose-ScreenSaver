ARose — macOS / Apple Silicon + Intel

English
INSTALL: Open the DMG and drag ARose onto Applications. Open ARose.app once,
then choose Screen Saver Settings… in its menu and select ARose in macOS.
After replacing the app, open the installed copy once. It automatically
refreshes the screen saver and any open System Settings window.
The extension is inside the app; no separate .saver installation is needed.
The app does not need to stay open while the system screen saver runs.
The embedded extension targets macOS 14+. The app itself supports macOS 13+.

The app and system saver have independent settings and saved figures.
The classic .saver remains in source for development, not as a public download.

UPDATES: Choose Check for Updates in the installed app. After confirmation,
Sparkle updates the whole app including its extension. Weekly checking is
optional and off by default; macOS may request approval for background activity.
The short hourly task only contacts GitHub when a week has elapsed and the
session is active and unlocked. It does not wake the Mac. There is no telemetry.

UNINSTALL: Disable weekly checks first, select another screen saver, and move
ARose.app to the Trash. If separately installed, remove ARose.saver from
Library/Screen Savers as well. Preferences are retained.

Development candidates are ad-hoc signed, not notarized. Public distribution
requires Developer ID signing and notarization. The extension uses private
macOS APIs. Runtime validation is on Apple M2 / macOS 27.0.1; older macOS and
Intel hardware acceptance remain pending. Do not disable Gatekeeper.

Česky
INSTALACE: Otevřete DMG a přetáhněte ARose na ikonu Applications (Aplikace).
Aplikaci ARose.app jednou spusťte. V nabídce zvolte Nastavení systémového
spořiče… a v macOS vyberte ARose. Po výměně aplikace jednou spusťte
nainstalovanou kopii; automaticky obnoví spořič i případné otevřené Nastavení
systému. Rozšíření spořiče je součástí aplikace;
samostatný .saver se neinstaluje. Aplikace nemusí při běhu spořiče zůstat otevřená.
Vložené rozšíření má cíl macOS 14+, samotná aplikace macOS 13+.

Aplikace a systémový spořič mají oddělená nastavení i uložené obrazce.
Klasický .saver zůstává ve zdrojácích pro vývoj, nikoli jako veřejný balíček.

AKTUALIZACE: V nainstalované aplikaci zvolte Zkontrolovat aktualizace. Po
potvrzení Sparkle aktualizuje celou aplikaci včetně rozšíření. Volitelná týdenní
kontrola je zpočátku vypnutá; macOS může požádat o povolení činnosti na pozadí.
Krátká hodinová úloha komunikuje s GitHubem až po uplynutí týdne a jen při
aktivním odemčeném sezení. Mac neprobouzí a neodesílá telemetrii.

ODINSTALACE: Nejprve vypněte týdenní kontrolu, vyberte jiný spořič a přesuňte
ARose.app do Koše. Samostatně nainstalovaný ARose.saver případně odstraňte ze
složky Library/Screen Savers. Preference zůstanou zachovány.

Vývojové balíčky mají místní ad-hoc podpis bez notarizace. Veřejná distribuce
vyžaduje Developer ID a notarizaci. Rozšíření používá neveřejná rozhraní macOS.
Provozní ověření proběhlo na Apple M2 / macOS 27.0.1; ověření starších systémů
a hardwaru Intel zatím chybí. Nevypínejte Gatekeeper.
