ARose ScreenSaver — macOS 13+, Apple Silicon / Intel

English
INSTALLER: Open the DMG, then open ARose Preview.app and choose Install ARose.
The app is copied to ~/Applications/ARose Preview.app and the saver to
~/Library/Screen Savers/ARose.saver. No administrator password is required.
Select ARose in System Settings → Screen Saver. Quit and reopen System Settings
if it was already open. Existing ARose settings and saved figures are preserved.

STANDALONE: Extract the standalone .saver.zip and open ARose.saver in Finder.
It needs no companion app or updater. Install future versions the same way.

UPDATES: The companion app has a Check for Updates button. After confirmation,
Sparkle downloads, verifies and installs the update, then the app refreshes its
managed screen saver on relaunch. Enable weekly checking in the ARose menu if
wanted; it is off by default. macOS may ask you to allow background activity.
A short hourly task checks locally whether a week has passed. Network checks
are deferred during inactivity/locking, do not wake the Mac, and contact only
the project's GitHub release infrastructure. Failed checks retry next week;
manual checks remain available. There is no telemetry or account requirement.

UNINSTALL: Disable weekly checks in the app first. Remove ARose.saver from your
user's Library/Screen Savers, and ARose Preview.app from your Applications.
Preferences are retained. System Settings manages locking and idle timeout.

Development candidates are ad-hoc signed and not notarized. Public distribution
requires Developer ID signing and notarization; do not disable Gatekeeper.
Intel compatibility is built, but hardware acceptance has been on Apple M2.

Česky
INSTALÁTOR: Otevřete DMG a aplikaci ARose Preview.app, poté zvolte Nainstalovat
ARose. Aplikace se uloží do ~/Applications/ARose Preview.app a spořič do
~/Library/Screen Savers/ARose.saver. Heslo správce není potřeba. Vyberte ARose
v Nastavení systému → Spořič obrazovky. Pokud bylo Nastavení systému otevřené,
ukončete je a znovu otevřete. Nastavení ARose i uložené obrazce zůstanou zachovány.

SAMOSTATNÝ SPOŘIČ: Rozbalte .saver.zip a otevřete ARose.saver ve Finderu.
Doprovodná aplikace není nutná. Nové verze nainstalujete stejným způsobem ručně.

AKTUALIZACE: Doprovodná aplikace má tlačítko Zkontrolovat aktualizace. Po potvrzení
Sparkle novou verzi stáhne, ověří a nainstaluje. Při opětovném spuštění aplikace
obnoví také jí spravovaný spořič. V nabídce ARose lze povolit týdenní kontrolu;
výchozí stav je vypnuto. macOS může vyžadovat povolení činnosti na pozadí.
Krátká hodinová úloha místně ověří, zda uplynul týden. Síťová kontrola se odkládá
při nečinnosti nebo zamčení, neprobouzí Mac a komunikuje pouze s infrastrukturou
GitHub Releases projektu. Neúspěšná kontrola se zopakuje za týden; ruční je
k dispozici kdykoli. Aplikace nevyžaduje účet a neodesílá telemetrii.

ODINSTALACE: Nejprve vypněte týdenní kontrolu v aplikaci. Odstraňte ARose.saver
z uživatelské složky Library/Screen Savers a ARose Preview.app z Applications.
Preference zůstanou zachovány. Zamykání i dobu nečinnosti spravuje systém.

Vývojové balíčky jsou podepsané místně, bez notarizace. Veřejné vydání vyžaduje
podpis Developer ID a notarizaci; nevypínejte Gatekeeper. Intel je podporovaný
sestavením, fyzické ověřování probíhalo na Apple M2.
