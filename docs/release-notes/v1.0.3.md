# ARose ScreenSaver 1.0.3

The first public release of an Amiga favorite, recreated for macOS and Windows with permission and support from original authors Wolfgang Breyha and Michael Matzl.

- **Original Amiga / Retro:** crisp dots, original palettes and faithful pattern sequences, with optional enlargement for modern displays.
- **Modern:** smooth rainbow points, adjustable glow and fluid playback on high-refresh displays, based on the same pattern mathematics.
- Independent companion app and system saver settings, optional continuation from the last figure, Czech and English interfaces.
- Manual update checks and optional weekly checks, disabled by default. Animation works offline, without an account or telemetry.

## Downloads

- **Mac:** download `ARose-ScreenSaver-v1.0.3-macOS-universal.dmg`, drag ARose to Applications, then open it once and select ARose in Screen Saver Settings. Requires macOS 14+; includes Apple Silicon and Intel binaries. Manual hardware validation has been on Apple M2.
- **Windows:** download `ARose-ScreenSaver-v1.0.3-Windows-x64-Setup.exe` and complete installation with administrator approval. Requires Windows 11 x64. No separate .NET or Visual C++ Redistributable is needed. The standalone `.scr` is also available for manual installation and updates.

The Mac update ZIP and appcast files are used by the updater; choose the DMG for a first installation. The classic Mac `.saver` remains available in source only. For instructions, see the [user guide](https://github.com/CooLajz/ARose-ScreenSaver/blob/main/docs/guide.md).

První veřejné vydání spořiče z Amigy, nově vytvořeného pro macOS a Windows se souhlasem a podporou původních autorů Wolfganga Breyhy a Michaela Matzla.

- **Originální Amiga / Retro:** ostré body, původní palety a věrné sekvence obrazců, s volitelným zvětšením pro dnešní displeje.
- **Moderní:** jemné duhové body, nastavitelná záře a plynulý pohyb i na displejích s vysokou obnovovací frekvencí, při zachování stejného matematického základu.
- Oddělená nastavení aplikace a spořiče, volitelné pokračování od posledního obrazce, české a anglické rozhraní.
- Ruční a volitelná týdenní kontrola aktualizací, zpočátku vypnutá. Animace funguje bez internetu, účtu a telemetrie.

## Stažení

- **Mac:** stáhněte `ARose-ScreenSaver-v1.0.3-macOS-universal.dmg`, přetáhněte ARose do Aplikací, jednou spusťte a vyberte v nastavení spořičů. Vyžaduje macOS 14+; obsahuje Apple Silicon i Intel. Ruční hardwarové ověření proběhlo na Apple M2.
- **Windows:** spusťte `ARose-ScreenSaver-v1.0.3-Windows-x64-Setup.exe` a potvrďte správce. Vyžaduje Windows 11 x64. Není potřeba doinstalovávat .NET ani Visual C++ Redistributable. Samostatný `.scr` zůstává dostupný pro ruční instalaci a aktualizace.

Aktualizační ZIP a appcast soubory pro Mac slouží aktualizátoru; pro první instalaci zvolte DMG. Klasický Mac `.saver` zůstává pouze ve zdrojovém projektu. Podrobnosti obsahuje [uživatelský průvodce](https://github.com/CooLajz/ARose-ScreenSaver/blob/main/docs/guide.cs.md).
