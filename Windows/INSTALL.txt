ARose ScreenSaver — Windows 11 x64

English
INSTALLER: Run ARose-ScreenSaver-v…-Windows-x64-Setup.exe. It asks for administrator approval, installs into Program Files, adds the
saver to the Windows system directory and creates Start menu shortcuts and an
uninstaller. Updates also require administrator approval. ARose opens the companion controls; ARose Preview opens an
interactive animation window. Select ARose in Windows Screen Saver Settings.
Updates preserve settings, saved figures and your existing saver selection.

STANDALONE: Save ARose.scr in a permanent folder, right-click → Install.
It requires no companion, .NET, Visual C++ Redistributable or updater framework.
Windows supplies the graphics APIs. Update manually by replacing the file.
Do not move it while it is selected as the system saver.

UPDATES: Choose Check for Updates in the companion app. After confirmation,
WinSparkle downloads and verifies the installer and runs it with a progress
window. Its DLL is included in the installation. Optional weekly checking is
off by default. A per-user Task Scheduler task runs briefly each hour, checks
the elapsed week locally and contacts GitHub only when due and the desktop is
active/unlocked. It does not wake the computer. Failed checks retry next week;
manual checks remain available. No telemetry or account is required.

Settings are in HKCU\Software\CooLajz\ARose. The installer uninstaller removes
the weekly task and installed files, but retains preferences and saved figures.
For a standalone copy, select another saver or None, then delete the file.
Windows continues to manage locking, passwords and idle timeout.

Commands: ARose.scr /c (settings), /s (full screen), /w (interactive preview).
In the preview: F1 settings, Space pause, R restart, F toggle full screen.
Esc leaves full screen; in a window it closes the preview. Languages: Czech/English.
Development builds are unsigned; corporate policies may disallow custom savers.

Česky
INSTALÁTOR: Spusťte ARose-ScreenSaver-v…-Windows-x64-Setup.exe. Vyžádá si potvrzení správce, nainstaluje aplikaci do Program Files a spořič
do systémové složky Windows, přidá zástupce do nabídky Start a umožní odinstalaci.
Aktualizace také vyžadují potvrzení správce.
ARose otevře ovládací aplikaci, ARose Preview interaktivní animaci v okně.
Vyberte ARose v nastavení spořiče Windows. Aktualizace ponechají nastavení,
uložené obrazce i dosavadní výběr spořiče.

SAMOSTATNÝ SPOŘIČ: Uložte ARose.scr do trvalé složky, pravým tlačítkem zvolte
Nainstalovat. Není potřeba doprovodná aplikace, .NET, Visual C++ Redistributable
ani aktualizační framework. Grafické funkce poskytují Windows. Novou verzi
nainstalujete ruční výměnou souboru. Dokud je vybraný jako spořič, nepřesouvejte jej.

AKTUALIZACE: V doprovodné aplikaci zvolte Zkontrolovat aktualizace. Po potvrzení
WinSparkle stáhne a ověří instalátor a spustí jej s ukazatelem průběhu. Potřebná
DLL je součástí instalace. Volitelná týdenní kontrola je ve výchozím stavu vypnutá.
Uživatelská úloha Plánovače se krátce spustí každou hodinu a místně ověří uplynutí
týdne. GitHub kontaktuje pouze při splnění intervalu a aktivní odemčené ploše.
Počítač neprobouzí. Po chybě zkusí další týden, ruční kontrola funguje kdykoli.
Neodesílá se telemetrie, není potřeba účet.

Preference jsou v HKCU\Software\CooLajz\ARose. Odinstalace odstraní týdenní úlohu
a nainstalované soubory, preference a obrazce ponechá. U samostatné kopie nejprve
vyberte jiný spořič nebo Žádný, poté soubor smažte. Zamykání, hesla a dobu
nečinnosti nadále spravují Windows.

Příkazy: ARose.scr /c (nastavení), /s (celá obrazovka), /w (interaktivní náhled).
V náhledu: F1 nastavení, mezerník pauza, R restart, F přepnutí celé obrazovky.
Esc vrátí celou obrazovku do okna; v okně náhled zavře. Jazyk: čeština/angličtina.
Vývojové sestavení nemá Authenticode podpis; firemní pravidla mohou vlastní
spořiče zakazovat.
